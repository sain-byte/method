Yang penting di versi ini: 4K/1440p langsung berhenti setelah metadata terbaca, jadi nggak akan sampai manggil "patchVideo()". Dan detector sekarang mempertahankan "mp4" object dari MP4Box supaya bisa masuk ke struktur track/sample-entry, bukan cuma informasi ringkasnya. MP4Box.js 2.4.1 memang mendukung progressive parsing di browser dan saat ini merupakan rilis package terbaru. Coba langsung test 3 file: 1080p SDR → 1080p HLG/HDR → 4K. Kalau HLG masih kebaca SDR, berarti kita tinggal bongkar struktur "colr" dari file HLG tersebut dan bikin fallback detector khusus—bukan balik ke detector string ngawur.
